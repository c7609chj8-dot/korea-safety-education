# 한국안전교육

Next.js + TypeScript 기반의 홈페이지 프런트엔드 초안입니다.

## 실행

```bash
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:3000 을 엽니다.

```bash
npm run typecheck
npm run build
npm start
```

## Vercel 배포

저장소 루트의 `vercel.json`에서 프레임워크를 Next.js로 지정하고 출력 디렉터리를 프레임워크 기본값으로 사용합니다. `public`은 Next.js 빌드 결과 폴더가 아닙니다.

- Git 저장소의 루트를 프로젝트 Root Directory로 사용합니다.
- Build Command는 `npm run build`입니다.
- Output Directory는 수동으로 `public`이나 `out`으로 지정하지 않습니다.
- 설정 변경 후 최신 커밋으로 새 배포를 실행합니다.
- 프런트엔드 초안은 Supabase 환경변수 없이 빌드할 수 있습니다.

## 현재 구현

- 반응형 홈, 교육 안내, 전화·지도 연결, FAQ.
- 메인 히어로 Swiper: 생성 이미지 5장, 자동 재생·일시정지, 좌우 이동, 페이지 표시, 터치 스와이프.
- 슬라이더는 마우스 진입 시 잠시 멈추고, 키보드 포커스·수동 조작 시 자동 재생을 중지합니다. 동작 줄이기 설정에서는 자동 재생을 끕니다.
- 샘플 교육 달력, 월 이동, 날짜 선택, 휴무·지난 날짜 구분.
- 선택 날짜가 반영되는 예약 절차 예시. 실제 개인정보를 입력하는 폼은 제공하지 않습니다.
- 개인정보 처리 안내(`/privacy`), 홈페이지 이용안내(`/terms`), 교육 대상·비용 안내(`/education-guide`).
- 모바일 메뉴·전화 버튼, 키보드 포커스와 본문 바로가기.

## 범위와 제한

- 일정은 요일을 기준으로 만든 예시이며 실제 운영일·공휴일·잔여석을 반영하지 않습니다.
- 예약 절차 예시는 고정된 가상 정보만 표시하며 실제 예약·취소·결제 기능이 없습니다.
- Supabase·관리자 인증·개인정보 수집·문자 발송은 아직 연결하지 않았습니다.
- 기관·연락처·교육비·시간은 기존 사이트의 안내를 옮겼으며 운영자가 재확인해야 합니다.
- 히어로에는 AI로 생성한 교육용 이미지 5장을 사용했습니다. 실제 교육장·강사 사진이 아니며, 구체적인 작업 절차를 설명하는 기술 도해가 아닙니다.
- 프리뷰의 검색 노출을 막도록 robots 메타데이터를 설정했습니다. 공개 오픈 전 설정을 검토해야 합니다.
- 외부 웹폰트 호출 없이 시스템 한글 글꼴을 사용합니다.
- Vercel의 호스팅·접속 보호 과정에서는 기술 정보가 처리될 수 있습니다. 현재 안내를 완성된 정식 개인정보 처리방침으로 간주하지 않습니다.
- 교육기관 등록 확인, 개인정보 보호책임자·수탁/국외이전/보유기간 확인, 취소·환불 정책 등 정식 운영 전 확인 항목은 `법적_점검_결과.md`를 참고하세요.
