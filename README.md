# 한국안전교육

Next.js + TypeScript 기반의 한국안전교육 운영 홈페이지입니다.

## 실행

```bash
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:3000 을 엽니다.

```bash
npm run typecheck
npm run build
npm start
```

## Vercel 배포

저장소 루트의 `vercel.json`에서 프레임워크를 Next.js로 지정하고 출력 디렉터리를 프레임워크 기본값으로 사용합니다. `public`은 Next.js 빌드 결과 폴더가 아닙니다.

- Git 저장소의 루트를 프로젝트 Root Directory로 사용합니다.
- Build Command는 `npm run build`입니다.
- Output Directory는 수동으로 `public`이나 `out`으로 지정하지 않습니다.
- 설정 변경 후 최신 커밋으로 새 배포를 실행합니다.
- 프런트엔드 초안은 Supabase 환경변수 없이 빌드할 수 있습니다.

## 현재 구현

- 반응형 홈: 기관 소개, 강사 소개, 교육 일정, 교육사진, 방문 전 확인사항, FAQ, 자료실, 관련기관, 오시는 길, 상담 안내.
- 메인 첫 화면: 제공받은 실제 교육 사진 5장을 순환하는 슬라이더, 큰 교육과정 제목, 교육시간·전화 문의 버튼. 6.5초 간격 자동 전환, 이전·다음, 일시정지·재생, 사진 선택, 터치 스와이프와 키보드 이동을 지원합니다. 동작 줄이기 설정에서는 자동 재생을 끕니다.
- 교육시간·준비물과 교육비·오시는 길을 같은 형식의 카드 3개로 안내하고, 교육시간·접수 안내를 기관 소개보다 먼저 배치합니다.
- IOSH의 사진 중심 구성과 NEBOSH의 여백·카드 구성을 참고해 한국안전교육의 남색·파랑 디자인으로 구성했습니다. 다른 기관의 이미지·로고·코드는 사용하지 않습니다.
- 한국 시간으로 갱신되는 교육 달력, 월 이동, 날짜 선택, 공휴일·지난 날짜 구분.
- 평일 12:40 접수 마감·토요일 예약제·휴무 안내와 전화·방문 접수 방법. 날짜별 문의는 대표전화로 연결합니다.
- 개인정보 처리 안내(`/privacy`), 홈페이지 이용안내(`/terms`), 교육 대상·비용 안내(`/education-guide`).
- 공식 홈페이지 QR 코드와 주소 복사·공유 버튼.
- 교육 현장 사진 6장과 확인된 강사 담당 분야를 제공합니다. 사진의 EXIF·IPTC 메타데이터만 제거했으며 원본 화상 데이터는 유지합니다.
- 공개 게시판 `/materials`는 제목 검색·분류·등록일·파일 열람·다운로드와 10건 단위 페이지 이동을 제공합니다. 메인에는 최근 3개 자료를 노출합니다.
- 제공된 안전보건공단 사고사례 PDF 6개는 원본과 동일하게 `public/materials`에 등록했습니다. 추가 자료는 `/admin/materials`에서 기존 관리자 등록 암호, 파일, 제목, 분류를 입력해 등록합니다. Vercel Blob에 저장되어 재배포 후에도 유지되며 공개 목록에 자동 표시됩니다.
- 등록 암호는 업로드 API에서 확인하며 관리 페이지는 검색 색인에서 제외합니다. Blob 연결 장애 시 기본 PDF 6개는 계속 표시하고 추가 자료 목록의 갱신 실패를 안내합니다.
- 모바일 메뉴·전화 버튼, 키보드 포커스와 본문 바로가기.
- 3일차: 히어로 사진과 설명 영역을 분리해 인물·실습 장면이 글에 가려지지 않도록 조정했습니다. 사진 선택 버튼은 최소 44×44px이며 사진 5장·자동재생 제어를 유지합니다.
- 교육 현장 사진 6장은 눌러 확대하고 이전·다음 버튼이나 방향키로 넘길 수 있습니다. 기본 dialog로 초점 이동·가두기·Escape 닫기를 지원하고 배경 스크롤을 잠급니다. 사진은 원본 화상 데이터를 유지합니다.
- 모바일 메뉴는 Escape·바깥 영역 선택·데스크톱 크기 전환 시 닫히며, 공개 자료실에도 하단 전화·교육시간 버튼을 제공합니다.

## 범위와 제한

- 달력은 요일별 운영 기준과 확인된 공휴일을 안내합니다. 실제 개강·휴강·잔여석은 실시간 연동하지 않으므로 전화 확인이 필요합니다. 공휴일 자료는 2027년까지 반영했으며 연도별·임시공휴일 갱신이 필요합니다.
- 가상 예약 화면은 제거했으며 온라인 예약·취소·결제 기능을 제공하지 않습니다.
- 별도 관리자 계정 로그인·온라인 접수·개인정보 수집·문자 자동 발송은 연결하지 않았습니다. 자료 등록은 서버가 확인하는 등록 암호로 제한합니다.
- 기관·연락처·교육비·시간은 기존 사이트의 안내를 옮겼으며 운영자가 재확인해야 합니다.
- 첫 화면·교육사진·공유 미리보기에는 제공받은 실제 교육장 사진을 사용합니다. 이전 생성 이미지 파일은 보관되어 있으나 현재 홈페이지에는 노출하지 않습니다.
- 운영 배포는 메인·교육안내의 검색 색인을 허용하고, 미리보기·로컬 환경은 noindex로 유지합니다. 개인정보·이용 안내는 운영에서도 noindex입니다.
- 외부 웹폰트 호출 없이 시스템 한글 글꼴을 사용합니다.
- Vercel의 호스팅·접속 보호 과정에서는 기술 정보가 처리될 수 있습니다. 현재 안내를 완성된 정식 개인정보 처리방침으로 간주하지 않습니다.
- 교육기관 등록 확인, 개인정보 보호책임자·수탁/국외이전/보유기간 확인, 취소·환불 정책 등 정식 운영 전 확인 항목은 `법적_점검_결과.md`를 참고하세요.

작업계획서는 [홈페이지_작업계획서.md](./홈페이지_작업계획서.md)를 참고하세요. 온라인 접수 대신 전화·방문 접수 안내를 운영합니다.

## Google 검색 등록

대표 주소는 `https://korea-safety-education.vercel.app/`이며, 운영 배포에서 `/robots.txt`와 `/sitemap.xml`을 제공합니다. `SITE_URL`과 `GOOGLE_SITE_VERIFICATION` 설정 예시는 `.env.example`에 있습니다.

Search Console 소유권 확인과 사이트맵 제출은 [구글_검색등록_안내.md](./구글_검색등록_안내.md)를 따르세요. 확인값은 Google에서 발급받아야 하며 SEO 코드만으로 소유권 확인이나 색인 완료를 보장하지 않습니다.

## 4일차 검색·로딩 개선

- 홈·교육비 안내·자료실의 제목과 설명, canonical·공유 이미지를 확인했습니다. 교육안내·자료실에는 현재 위치와 WebPage/CollectionPage·BreadcrumbList 구조화 데이터를 추가했습니다. 기관 등록번호는 제공된 등록증에 근거해 표시합니다.
- 사이트맵에는 공개 페이지 3개와 실제 교육사진·등록증 이미지 경로를 포함합니다. 운영의 관리자·API 응답, 미리보기의 모든 응답에는 HTTP `X-Robots-Tag: noindex, nofollow`를 적용합니다.
- 네이버 소유확인 값은 `NAVER_SITE_VERIFICATION`, 구글은 `GOOGLE_SITE_VERIFICATION`에 발급된 content 값만 입력하고 운영으로 재배포합니다. 계정 소유확인·사이트맵 제출·실제 검색 색인은 별도 절차입니다. 임의의 인증값은 게시하지 않습니다.
- 이미지 파생 크기는 최대 2048px로 제한하고 160px 썸네일 크기를 추가했습니다. 원본 사진과 공유 이미지는 유지합니다. 달력은 한국 자정과 화면 복귀 때 갱신하며 매초 확인을 제거했습니다. 초기 달력 자리도 예약해 모바일 화면 밀림을 줄입니다.
- 속도 점수·검색 순위 상승이나 실제 사용자 Core Web Vitals 개선 수치는 측정 전 보장하지 않습니다.

공식 참고: [Google 경로 구조화 데이터](https://developers.google.com/search/docs/appearance/structured-data/breadcrumb), [네이버 소유확인](https://searchadvisor.naver.com/guide/faq-start-register).


## 최종 점검 및 유지관리

- 2026-11-27: Next.js 16.4.6으로 패치하고, `@vercel/cli-config`가 고정하던 Zod를 같은 4 계열의 수정 버전 4.6.7로 제한해 사용합니다. `overrides`는 이 보안 패치를 위한 설정이며 상위 패키지가 수정되면 재검토합니다.
- `npm test`는 한국 시간·달력과 자료 등록 권한·파일 제한·서명 없는 콜백 거부를 확인합니다. 자료 등록 테스트는 가상의 로컬 전용 암호와 토큰으로 실행하며 외부 통신을 금지합니다. 실제 Blob 파일은 생성하지 않습니다.
- 관리자 화면: `/admin/materials`. 공개 자료실: `/materials`. 관리자 화면 자체는 로그인 화면처럼 열리지만 파일 등록 토큰은 암호 검증 후에만 발급합니다. 검색 제외는 접근 통제를 대신하지 않습니다.
- 자료 등록은 PDF·DOC·DOCX, 파일당 10MB 제한입니다. 실제 파일 전송 완료 여부는 운영자가 등록 암호를 입력해 확인해야 합니다.
- Google 검색 설정 코드와 사이트맵 제공은 완료했지만 Search Console 소유권 확인·사이트맵 제출·검색 반영 여부는 별도로 확인해야 합니다.
- 교육기관 등록증 제156호(2022-01-04)를 기관 소개와 교육안내에 게시했습니다. 세무상 사업자등록번호와 구분하며, 세무 사업자등록증 이미지는 공개하지 않습니다. 등록증 JPEG는 EXIF·IPTC만 제거하고 화상 데이터는 유지했습니다.
- 2026-11-27 공단 건설기초안전 교육포털에서 양산 기관명·주소·전화번호 일치를 확인했습니다. 무료교육 참여 여부는 참여, 진행현황은 종료였습니다. 다섯 지원 대상(만 55세 이상·만 20세 이하·장기실업자·장애인·기초생활수급자)과 선착순 원칙을 안내하되, 현재 지원 재개 여부·잔여 인원·증빙서류는 전화로 확인하도록 표시했습니다. 공단 조회: https://cobedu.kosha.or.kr/intro/institution
- 센터 안내 교육비 80,000원과 신분증 필수 지참, 상가 주차장이나 아파트 뒤편 노상의 무료 주차장을 안내합니다. 강사별 자격·경력은 운영자 요청에 따라 생략합니다.
- 2028년 공휴일 및 임시공휴일은 운영자가 갱신합니다.

검수 중 영문 파일 제목의 중간 단어가 삭제되는 문제를 재현하고 수정했습니다. `Safety-Training-Guide` 같은 제목도 전체 표시·검색되며 재발 방지 테스트를 포함합니다.

운영 점검은 저장소에서 `npm run check:live`로 다시 실행할 수 있습니다. 이 명령은 공개 페이지·내부 앵커·PDF 원본 일치·자료실 연결·검색 설정을 확인하고, 암호 없는 업로드 요청이 차단되는지 확인합니다. 실제 파일을 등록하거나 삭제하지 않습니다.

남은 운영 확인은 다음과 같습니다.

- 관리자 기존 암호를 입력한 실제 추가 파일 전송·공개 목록 반영 확인. 현재 검수는 등록 화면·권한 거부·허용 토큰 발급과 파일 제한까지이며 실제 새 Blob 업로드는 수행하지 않았습니다.
- 구글·네이버 소유확인 값 설정, 사이트맵 제출과 실제 검색 색인 확인.
- 실제 iPhone·Android에서 전화 연결·지도 앱 전환·파일 열람 확인. 브라우저 화면 크기 검수는 실제 단말기 검수를 대신하지 않습니다.
- 무료교육 지원 재개 여부·잔여 인원, 임시 휴강·공휴일 변경은 운영자가 갱신합니다.

파일명 처리 참고: [Vercel Blob SDK의 임의 접미사 옵션](https://vercel.com/docs/vercel-blob/using-blob-sdk).
